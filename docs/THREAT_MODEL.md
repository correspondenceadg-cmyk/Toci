# Threat model

| Tier | Adversary | Capability |
|---|---|---|
| T1 | Casual grabber | Unlocks a trivial PIN, browses the gallery |
| T2 | Partner with tools | Hours of physical access, Play Store recovery app |
| T3 | Forensic consumer kit | Cellebrite-class logical extraction |
| T4 | Laboratory | Chip-off, raw die read, FTL reverse-engineering |
| T5 | State / hostile border | Seizure, detention, later commercial extraction |

Survival per tier is filled in as the verification gate is tested against the sacrificial matrix. See `DEVICE_MATRIX.md`.
